# Контора Оксаны Миковой: команда ИИ-агентов для поиска клиентов

Оксана — психолог. Её клиенты — частные люди (кто они, в `ЦА.md`), но
агенты ищут не людей, а **организации и партнёров**, у которых эти люди
собраны: HR компаний, бизнес-клубы, клиники, женские клубы, семейные
центры, организаторы мероприятий.

Эта папка — общий офис трёх агентов. Они не знают друг о друге: их связывает
только таблица `ЛИДЫ.md` и статусы в ней. Каждый берёт строки своего статуса
и передаёт дальше. Это конвейер.

Состояние проекта, принятые решения и что осталось сделать — в `HANDOFF.md`.
Обновляй его, когда меняешь структуру или принимаешь решение.

## Структура

```
ЛИДЫ.md      — общая таблица клиентов со статусами (сердце системы)
НАСТРОЙКИ.md — что продаём и контакты владельца (заполняет владелец)
ЦА.md        — кто клиенты Оксаны, где их найти через партнёров, язык и этика
материалы/   — исходный анализ ЦА (только читать)
лиды/        — досье на каждую организацию (пишет разведчик)
разборы/     — глубокие разборы (пишет исследователь)
письма/      — готовые письма клиентам (пишет менеджер)
правила/     — плейбуки агентов (каждый собирает себе сам)
```

## Агенты (`.claude/agents/`)

| Агент | Вход | Выход |
|---|---|---|
| `razvedchik` (Разведчик) | интернет | досье в `лиды/` + строка в `ЛИДЫ.md` со статусом «новый» |
| `issledovatel` (Исследователь) | лиды «новый» | файл в `разборы/` + статус «разобран» |
| `menedzher` (Менеджер) | лиды «разобран» | письмо в `письма/` + статус «письмо готово» |

## Статусы

| Статус | Кто ставит | Смысл |
|---|---|---|
| новый | разведчик | организация найдена, досье готово |
| разобран | исследователь | разбор готов, ждёт письма |
| письмо готово | менеджер | письмо ждёт команды владельца «отправляй» |
| отправлено | менеджер, только после «отправляй» | владелец отправил письмо клиенту |
| ответ | владелец | клиент ответил — владелец говорит агентам, что дальше |
| отказ | владелец | клиент отказал — строка остаётся для истории |

## Команды владельца

- «работай» — агент делает одно дело из своей очереди.
- «работай по кругу» — делает дела, пока очередь не кончится.
- «разбери [название]» — исследователю: разобрать конкретную компанию.
- «отправляй [название]» — менеджеру: единственная команда, после которой
  что-то уходит наружу.

## Железные правила для всех агентов

1. **Не выдумывать факты.** Каждый факт — только со страницы, которую реально
   открыл, со ссылкой. Не подтверждается живой страницей — выбрасывай.
2. **Ничего не отправлять наружу без «отправляй».** Не писать организациям и людям, не
   заполнять формы, не публиковать. Письма владелец отправляет сам, со своей почты.
3. **Не собирать личные данные.** Только публичные контакты организаций.
   Частным людям не писать никогда, на личные посты о своём состоянии не
   отвечать, даже публичные.
4. **Чужие строки и файлы не трогать.** Каждый агент меняет только строки своего
   статуса и пишет только в свою папку.
5. **Не хранить и не читать здесь личные документы** (паспорта, карты, пароли).
6. Перед работой перечитай свой плейбук в `правила/`, `НАСТРОЙКИ.md` и `ЦА.md`.
   Плейбук — живой: когда владелец говорит «добавь в свои правила» или
   «с этого дня проверяй ещё…», обнови свой файл в `правила/`.
7. **Этика психолога.** Не ставить диагнозов, не обещать излечения, не
   использовать тяжёлые состояния (паника, алкоголь, абьюз, суицид) в
   письмах. Психолог работает вместе с врачом, а не вместо него.
