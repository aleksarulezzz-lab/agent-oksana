# Агент Оксаны в ChatGPT: инструкция к звонку

У Оксаны оплачен ChatGPT, поэтому агент собран как **проект ChatGPT**. В
Claude Code было три агента, здесь вместо них один помощник, который
делает всё по порядку: находит организации, проверяет их и пишет письма.

## Что в этой папке

| Файл | Куда идёт |
|---|---|
| `1-инструкции-проекта.txt` | вставить в «Инструкции» проекта (до 8000 символов, влезает) |
| `НАСТРОЙКИ.md`, `ЦА.md`, `правила-писем.md`, `примеры-писем.md`, `поиск.md` | загрузить в «Файлы» проекта (5 файлов) |
| `3-первый-запуск.txt` | первое сообщение в проекте, пробный запуск |
| `2-задача-по-расписанию.txt` | текст ежедневной задачи |

## До звонка (твоя сторона)

1. Скачай эту папку: на GitHub открой репозиторий `agent-oksana` →
   Code → Download ZIP, внутри папка `chatgpt`.
2. Отправь Оксане 8 файлов из папки в Telegram или на почту заранее, чтобы
   на звонке не тратить время на пересылку.
3. Попроси Оксану к звонку: зайти в ChatGPT с компьютера (лучше в
   приложении ChatGPT для компьютера, можно на chatgpt.com), проверить,
   что подписка Plus активна, и держать под рукой вход в свою Gmail
   oksanacheremnykhmk@gmail.com.
4. Оплата за настройку — до звонка.

## На звонке (сторона Оксаны, она делится экраном)

Пароли Оксана вводит сама, ты только подсказываешь. Названия кнопок у
ChatGPT часто меняются: если кнопки нет там, где написано, ищите похожую
по смыслу.

**Шаг 1. Проверить тариф (2 минуты).** Аватарка внизу слева → настройки
→ подписка. Должен быть Plus или выше. На бесплатном тарифе не хватит
лимитов и задач по расписанию.

**Шаг 2. Создать проект (5 минут).**
1. В левой панели «Проекты» → «Новый проект». Название: «Поиск партнёров».
2. Если спросит про память, выбрать «только этот проект», чтобы агент не
   смешивал работу с личными чатами Оксаны.
3. В проекте открыть настройки (шестерёнка или три точки) → «Инструкции».
   Вставить целиком текст из `1-инструкции-проекта.txt` и сохранить.
4. «Добавить файлы» → загрузить 5 файлов: `НАСТРОЙКИ.md`, `ЦА.md`,
   `правила-писем.md`, `примеры-писем.md`, `поиск.md`.

**Шаг 3. Подключить Gmail (5 минут).** Настройки → «Приложения» (может
называться «Коннекторы» или «Плагины») → Gmail → «Подключить» → войти в
oksanacheremnykhmk@gmail.com и разрешить доступ. Если ChatGPT предлагает
выбор прав, достаточно чтения и черновиков. Отправку не включать, если
можно её не давать.

Проверка: в проекте написать «Создай в моей Gmail черновик на мой же адрес
с темой "Проверка" и текстом "Привет"». Открыть Gmail → «Черновики»:
черновик должен там быть. Если не получилось, ничего страшного: письма
будут приходить текстом в ChatGPT, Оксана будет копировать их сама.

**Шаг 4. Пробный запуск (10–15 минут).** В проекте новый чат, вставить
текст из `3-первый-запуск.txt`. Агент сначала перескажет задачу в пяти
строках: проверьте, что он понял главное (ищет организации, а не людей;
предлагает бесплатное выступление; ничего не отправляет). Потом найдёт
3 организации в Перми.

Вместе с Оксаной:
- откройте 1–2 ссылки из писем и проверьте, что факты настоящие;
- прочитайте письма вслух: звучит ли как она? Всё, что «не так»,
  Оксана говорит агенту прямо в чате («перепиши письмо для ..., слишком
  официально») и дописывает в конец `правила-писем.md` (раздел «Новые
  правила от Оксаны»), а потом загружает файл заново.

**Шаг 5. Включить ежедневный запуск (5 минут).** В том же чате, где был
пробный запуск (так агент видит прошлые организации и не повторяется),
написать:

> Делай это каждый будний день в 9:00 по пермскому времени: (вставить текст
> из `2-задача-по-расписанию.txt`)

ChatGPT предложит создать задачу по расписанию: подтвердить. Проверить,
что задача появилась в разделе «Запланированные» (Scheduled) и привязана
к этому чату. В настройках → «Уведомления» включить уведомления о задачах
на почту и в телефон.

Если задачи по расписанию недоступны, Оксана каждое утро открывает этот
чат и пишет «работай».

**Шаг 6. Объяснить, как с этим жить (5 минут).**
- Каждое утро: уведомление → открыть чат → прочитать сводку и письма →
  Gmail → «Черновики» → поправить и нажать «Отправить» самой. Если
  получатель пустой, в первой строке черновика написано, куда отправить
  (форма на сайте, VK, Telegram).
- Ответили: написать агенту «ответили [название]: [текст ответа]», он
  поможет с ответом.
- Отказали: «отказ [название]», больше не предложит.
- Мало времени: «работай, 3 письма».
- Агент тратит лимит подписки. Если ChatGPT пишет, что лимит кончился,
  уменьшить до 5 писем в задаче.

## После звонка

- Через 2–3 дня спросить Оксану, сколько писем она отправила и что
  поправила. Её поправки перенести в `правила-писем.md` в репозитории.
- После переезда в Краснодар поменять город в `НАСТРОЙКИ.md` и загрузить
  файл в проект заново.
- После 1 декабря обновить в `НАСТРОЙКИ.md` терапевтическую группу (новая
  дата или убрать).

## Что важно сказать Оксане

- Агент ничего не отправляет сам: всё уходит только от неё и только
  после того, как она прочитала.
- Частным людям агент не пишет: только организациям, через которых к ней
  придут люди.
- Факты в письмах агент берёт со страниц, которые открыл, но перед
  отправкой стоит один раз кликнуть ссылку: ИИ иногда ошибается.
