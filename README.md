# Агент для поиска клиентов: Оксана Микова, психолог

Команда из трёх ИИ-агентов для Claude Code: сами ищут организации, у которых
собраны клиенты Оксаны (HR компаний, бизнес-клубы, клиники, женские клубы,
семейные центры, организаторы мероприятий), разбирают их и готовят письма
с предложением: выступление, встреча для команды, программа, партнёрство.
Частным людям агенты не пишут. Кто ЦА и где её искать — в [ЦА.md](ЦА.md). Собрано по инструкции
«Собери команду ИИ-агентов в Claude Code».

```
Разведчик  →  Исследователь  →  Менеджер  →  ты говоришь «отправляй»
 «новый»        «разобран»     «письмо готово»     «отправлено»
```

Агенты не знают друг о друге: их связывает только таблица `ЛИДЫ.md` и статусы.
Подробно о статусах и правилах — в [CLAUDE.md](CLAUDE.md).

## Быстрый старт

1. Нужна платная подписка Claude (хватит Pro) и приложение Claude или
   Claude Code в терминале.
2. Склонируй или скачай эту папку и открой её в режиме **Code**.
3. Заполни в [НАСТРОЙКИ.md](НАСТРОЙКИ.md) всё, что в [квадратных скобках]:
   город, цены, главное предложение для первого письма, контакты для подписи.
4. Скажи в чате: «разведчик, работай» или набери `/razvedka`.

При первом запуске каждый агент сам изучит лучший опыт в интернете и соберёт
себе плейбук в `правила/`. Перед действиями агент спрашивает разрешение —
жми **Allow**, когда согласен.

## Команды

| Что сказать | Слеш-команда | Что произойдёт |
|---|---|---|
| «разведчик, работай» | `/razvedka` | найдёт 10 организаций-партнёров, досье в `лиды/` |
| «разбери [название]» | `/razberi [название]` | глубокий разбор в `разборы/` |
| «менеджер, работай» | `/pismo` | письмо в `письма/` |
| «работай по кругу» | `/konveier` | весь конвейер, пока очереди не кончатся |
| «отправляй [название]» | `/otpravlyai [название]` | покажет письмо и адрес; отправляешь ты сам |

Агентов можно дорабатывать обычными фразами: «ты упустил вот это — добавь в
свои правила», «с этого дня проверяй ещё…». Они обновят свой плейбук в
`правила/`.

## Структура

```
ЛИДЫ.md       — общая таблица клиентов со статусами
НАСТРОЙКИ.md  — что продаёшь и твои контакты
ЦА.md         — кто клиенты, где их найти через партнёров, язык и этика
материалы/    — исходный анализ ЦА
лиды/         — досье на организации (разведчик)
разборы/      — разборы (исследователь)
письма/       — письма (менеджер)
правила/      — плейбуки агентов
.claude/agents/   — сами агенты: razvedchik, issledovatel, menedzher
.claude/commands/ — слеш-команды
```

## Безопасность

- Агенты не выдумывают факты: всё только со страниц, которые реально открыли.
- Агенты ничего не отправляют сами. Письмо уходит только с твоей почты, после
  того как ты его прочитал.
- Не храни в папке личные документы, пароли и карты: агенты читают всё.
- Лимиты подписки обновляются каждые 5 часов. Агент «устал» — подожди.
- Бэкап — это копия папки (или `git push`).
